# Recommended for Russia: services that are better reached directly than through a
# tunnel. The Split page adds them to the profile being edited with "Recommended for
# Russia", and a new installation starts with them in its Default profile.
#
# One rule per line, UTF-8 without a byte order mark, in the order they are added.
# Blank lines and lines that begin with # are ignored; a rule has no comment after it.
# A rule is what the Split page accepts: a name, or *.name for the name and everything
# under it. Never a top-level domain alone (*.ru): the core's domain filter refuses it.
#
# One file for both apps. The desktop app has it compiled in (cmake/SharedData.cmake
# writes the include file that src/core/AppSettings.cpp reads), and the Android app has
# it copied into its assets (android/app/build.gradle). tests/test_appsettings.cpp and
# android/app/src/test/.../RussiaListTest.java check that each uses these lines and no
# others, and that every one of them is a rule the app takes.
